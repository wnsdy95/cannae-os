# Readiness Drop Fixtures

`run-readiness-drop-revocation-fixtures.js` exercises the actual dispatcher,
pending completion, revocation, resumed/initial authority, cross-mission matching,
non-resurrection, gateway begin/publication and direct history-reader rejection.
Synthetic actors and authored observations are not actual trained models or
authenticated evaluator evidence. Exact role/task matching is not the complete
capability registry. Follow [the operating procedure](../docs/readiness-drop-reconciliation.md).

`write-samples.js` regenerates only two synthetic structural examples for
`schema-files/readiness-drop-reconciliation.schema.json`. It never rewrites
retained events, checkpoints, consent or actual execution evidence.
