# Workload Control Fixtures

`node run-workload-control-fixtures.js` exercises actual local worker input,
real report rejection and digest-only receipt retention on isolated synthetic
repositories. No real model, owner approval or installed runtime is exercised.

`node workload-control-fixtures/write-samples.js` regenerates only six synthetic
structural metadata examples. Their fictional fingerprints and process fields
are not observations of an executed worker. Never regenerate retained mission
evidence or treat a sample's `passed` field as publication authority.
