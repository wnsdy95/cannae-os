# Disciplined Method Fixtures

These tests use isolated temporary repositories, captured synthetic requests,
full USER-log adoption, exact policy/lease admission, actual local fixture file
reads, provider callbacks, retained SITREPs and real revocation consumers. They
never create a real console owner, approve human work, grant release, deploy
infrastructure or prove authenticated human presence.

Run `node run-disciplined-initiative-fixtures.js` for integration. Run
`node disciplined-initiative-fixtures/write-samples.js` only when intentionally
regenerating the twelve illustrative valid/invalid contract samples and policy draft. Retain
reviewed examples across ordinary tests rather than rewriting them each run.
`run-method-deviation-contract-fixtures.js` provides bounded pure checks for
routed wave controls; it does not claim the separate integration suite ran.

Coverage includes exact planned execution, finite reviewed substitutions,
missing before/after reports, complete task/roster commitments, real step/order
and reporting holds, actual revocation, late-result reporting, retained unknown
effects, publication races, canonical manifest introduction order, forged result
reports, metadata-as-work rejection and both real provider wrappers.
Metadata cases include actual derived SITREPs without type tags and reformatted
plain-text/binary copies. `run-skill-control-evidence-fixtures.js` separately
exercises actual report publication, every routed control, ordinary JSON work
and a publication-time alias race in legacy data-only waves; it does not replace
this suite's dispatch integration.

The separate full DI ruleset, novel method equivalence, reordering/insertion,
all degeneration patterns, readiness recovery, mandatory rollout for legacy
workflows and protected production paths remain explicit unfinished work.
Schema validity and these synthetic tests do not complete the eight-part goal.
