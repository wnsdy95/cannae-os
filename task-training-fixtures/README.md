# Task Training Evidence Fixtures

These in-progress fixtures consume actual dispatch admissions/checkpoints and
actual local file-read output alongside owner-enrolled synthetic force definitions.
They are not a real model performance or owner-ceremony proof. Synthetic session
bindings are explicitly signed by the fixture in its isolated private test store;
those legacy mappings are not the separate
[owner-session consent candidate](../docs/training-session-consent.md).
Qualification and operational grant consumers remain incomplete.

Run `node run-task-training-fixtures.js`. Positive intake binds observed bytes;
negative cases require exact scope, case, trust-key, provider-result and output
substitution denials. All qualification, model-attestation, execution, restoration
and release flags remain false. See [the full boundary and remaining pipeline](../docs/task-training-evidence.md).
