# Native Training Transfer Fixtures

These fixtures exercise the actual local owner HTTP/worker/collector/publication
path with temporary synthetic accounts and a measured fake process. The native
owner path does not export a fixture signing key or manually sign its consent.
It verifies the operator's actual producer instead. No real owner, credential,
model call, installed skill or existing daemon is touched.

Contract fixtures preserve exact generated schemas, nested existing release
schemas, samples, signatures and non-authority semantics. Runtime fixtures
exercise exact handling review, original bytes, refusal boundaries, partial
publication, logout and orphan inventory. They are not training evaluation,
qualification, complete protected deployment or full-root acceptance.
