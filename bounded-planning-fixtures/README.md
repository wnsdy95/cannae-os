# Bounded Structural Planning Fixtures

`support.js` derives proposed capability/policy bounds from existing synthetic
compiler/adoption scaffolding. Production generation imports no sample or test
helper and accepts no complete caller-authored plan. `write-schemas.js` derives
the two schemas from strict Zod contracts; `write-samples.js` regenerates only
the four synthetic pairs.

`node run-bounded-planning-fixtures.js` exercises actual task allocation,
bounded search, budget/roster failure, exact publication, provenance, fresh
coverage, retained USER fixture adoption, context/policy/lease/next-call admission,
parent expenditure, revision/supersession and both target-explicit wrappers.
The fixtures use zero model calls and no real owner action. Controller calls
test real admission/settlement logic, not native target execution or independent
semantic planning quality. Preserve failed observations separately from any
later corrected-source proof.
