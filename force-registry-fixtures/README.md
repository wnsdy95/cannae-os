# Force Registry Enrollment Fixtures

Run `node run-force-registry-contract-fixtures.js` for structural, semantic,
signature, and non-work classification checks. Run
`node run-force-registry-fixtures.js` for actual authenticated HTTP, persistent
registry replay, session expiry, disclosure, and partial-publication checks.
All accounts, keys, repositories, and supporting material are synthetic.

With Playwright and its Chromium runtime available, run
`node force-registry-fixtures/browser-check.js --output <private-output-directory>`
for actual desktop/mobile approval, incomplete-preview rejection and changed
display denial. Screenshots are synthetic; never automate the real owner's
password or bootstrap ceremony.

`write-samples.js` regenerates ten deterministic schema examples only. Its
public key is not a trusted operator identity. Never regenerate retained owner
decisions, event history, failed evidence, or operational consent.

An enrolled definition is always unassessed and grants neither task execution,
qualification, release, nor standing-department activation. These suites do not
prove native model observation, training, an operational grant consumer,
protected host isolation, or production rollout.
